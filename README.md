# 视频剪辑技能

把本地拍摄素材整理成有故事、对白完整、方便分享的家庭或旅行短片。内容来自一次实际完成的剪辑：选素材、多轮按时间修改、补充亲子互动、压缩分享版、制作封面和清理中间文件。

这是供 Agent 读取的技能文档，使用 FFmpeg / FFprobe 执行剪辑。仓库只保存方法与示例；实际素材、照片、音频和成片放在本地项目中。

## 使用

让 Agent 读取 [SKILL.md](skills/video-edit/SKILL.md)，再提供素材目录和要求。也可以把 `skills/video-edit/` 整个目录放入所用 Agent 的技能目录。

例如：

> 读取 skills/video-edit/SKILL.md。素材在 /path/to/media，这是一次家庭周末出游。先给我三个剪辑方向，选定后导出高清版和约 25MB 的分享版，并做好封面。

已明确方向时，可以直接要求剪辑：

> 按温暖纪实风剪辑，重点保留母子互动，保留少量自然风景。把 00:58 附近镜头摇离木船的尾巴删掉；说完指定台词后直接接下一个镜头。

## 本地项目结构

```text
my-film/
├── media/             # 原片或原片所在目录的引用
├── edit-plan.json     # 镜头清单、修订所依据的版本
├── work/              # 联系表、渲染片段、临时音轨
└── output/
    ├── film-4k.mp4
    ├── film-1080p.mp4
    ├── film-share.mp4
    └── cover.jpg
```

FFmpeg 和 FFprobe 是基础依赖。需要生成联系表时可用 Python 与 Pillow；需要生成或编辑封面图时遵循当前 Agent 环境的图像工具规则。

## 这次实践中最值得保留的经验

- 看完整个候选镜头的运动过程。中间一帧好看，尾巴仍可能摇离主体。
- 用户报时间时，先定位到用户实际看过的版本；连续删片会改变后面的时间。
- 按台词结束位置剪对白，保留自然句尾；波形和静音只能辅助定位。
- 家庭片优先保留互动的开始、反应和结果，把较弱的空镜让给这些内容。
- 只给 MP4 添加封面图还不够：同时处理首帧，并单独交付封面图片。
- 拼接视频统一时间基。容器总时长正确，也可能掩盖视频轨道变短的问题。
- 最终交付验证后，再按用户要求删除旧版和缓存；保留原片、最终导出和剪辑清单。
