# 选片与多轮修订

## 建立素材索引

先扫描用户指定的目录，结合文件名、拍摄元数据和用户描述确定素材范围。复制时间不一定是拍摄时间；“今天拍的”应结合用户所在时区核对。

每条素材记录文件路径、时长、画面尺寸、帧率、色彩标记、旋转和音轨。DJI 同编号的 `.MP4` 与 `.LRF` 是原片和代理关系，浏览时只计作一条素材。

按每 2–5 秒一帧生成联系表，再对候选片段加密采样。联系表用于筛选，最终入出点需要连续查看或逐帧检查。

## 选镜头

候选镜头要有明确主体和内容：走来、发现、递东西、拥抱、回应、一起玩。家庭片可以让互动多停留几秒，但要看得到动作或情绪的变化。

| 情况 | 处理 |
| --- | --- |
| 远景里的鸟太小，看不清主体 | 删除，或者只用确实能辨认的部分 |
| 先对准木船，随后摇向旁边，下一镜又回到船 | 在摇开前结束，直接接船上近景 |
| 前半段人物完整，后来仰拍天空或裁掉头部 | 保留人物完整的范围 |
| 孩子抱住妈妈，之后松手并有反应 | 保留完整小过程，比单独截几秒更有记忆点 |
| 风景重复、过暗，或者只承担占位 | 用更好的互动替换；保留少量有层次的风景 |
| 摄影者自拍、镜头快速翻转 | 用户要求删除后从清单移除，后续版本持续继承 |

检查从入点到出点的整个运动过程。中间一帧构图好，不能代表尾部也适合保留。

## 给方案时具体到结构

只在用户希望比较方向或尚未选定风格时提供方案。例如：

1. **温暖纪实：** 环境开场 → 走入场景 → 发现与互动 → 一次较完整的亲子过程 → 合影收尾。对白和原声优先。
2. **轻快短片：** 直接用有吸引力的动作开场，减少空镜，按动作与音乐组织短镜头。
3. **周末日记：** 按游玩路线串联，保留更多对话、停顿与环境声。

时长是内容选择的结果，不能沿用已经被用户取消的长度限制。用户选定方向后，后续修订保持同一条叙事。

## 镜头清单是时间轴的依据

`source`、`in`、`duration` 表示原片和原片时间；`timeline_start` 是成片时间。示例里的相对素材路径以项目根目录解析。

`transition_after` 表示与下一条镜头重叠的秒数，硬切为 0。最后一条必须是 0，重叠必须短于相邻两条镜头。

```text
下一条 timeline_start = 当前 timeline_start + duration - transition_after
成片时长 = 所有 duration 之和 - 所有 transition_after 之和
```

以固定帧率渲染时，把剪点落实到帧。30fps 的一帧约为 0.0333 秒。

## 按用户时间定位修改

1. 记录这轮意见对应的已交付文件 `base_export`。
2. 从该文件的镜头清单查出覆盖用户时间段的镜头。
3. 将成片时间换算成原片入出点，检查该范围及前后余量。
4. 所有意见映射完成后，再修改清单并重算时间轴。
5. 交付新版本时更新版本标识；内部未交付草稿不改变本轮基准。

例如，用户说基准版 58–60 秒镜头摇开。即使内部草稿已经先删去前面 4 秒，仍先查看基准版的 58–60 秒，再定位原片；不能直接删草稿的 58–60 秒。

新增、删减镜头会改变转场关系。删除一个带转场的镜头时，重新决定相邻两镜头的衔接；避免留下 0.2–0.5 秒的尾巴闪回。必要时把尾巴与被删范围一起收掉，用自然风景或相邻完整动作衔接，并在修订记录说明范围。

## 按对白找剪点

先完整保留目标句，再删句后停顿和多余反应。通常在句尾之后保留约 80–150ms 的余量；淡出落在余量里，而不是压住最后一个音节。

如果可以听取或转写，结合原声判断语义与呼吸。如果环境无法处理音频输入，使用用户给出的台词位置、波形和静音段定位候选边界，保留适当余量；明确没有完成听辨。

RMS 或静音检测只能说明能量变化。低声、清辅音和尾音也可能能量很小，不能把静音阈值当作一句话结束的唯一证据。

## 修订后的检查

每个改动至少看剪点前后各约一秒；动作、淡化和运镜较长时扩大范围。检查目标内容确实已删，保留部分没有被误伤，对白与动作没有提前中断。

逐次继承已经接受的修改，如去自拍、去晃动、指定素材开场和增加互动。交付记录应说明最终实际变化，不混入已放弃的内部方案。
